# 独立游戏视频 EP05 · Steam 商店页

本仓库存放《独游视频》EP05（Steam 商店页：玩家点进来，为什么看两眼就走了）的素材与成片。

## 目录结构

| 路径 | 内容 |
| --- | --- |
| `录音/录音1(3).m4a` ~ `录音/录音10.m4a` | 口播录音 1–10（按编号顺序使用） |
| `背景音乐/于行,仁辰 - 糖果物语.mp3` | BGM《糖果物语》 |
| `视频/EP05_Steam商店页_预览版_无口播.mp4` | 预览版（示意游戏版，无口播，Git LFS） |
| `视频/EP05_Steam商店页_真实案例版_预览版_无口播.mp4` | 预览版（真实案例版，无口播，Git LFS） |
| `成片/EP05_Steam商店页_成片.mp4` | **正式成片**（口播 + 新字幕 + BGM，基于真实案例版，约 95 MB，普通 Git 文件） |
| `成片/EP05_Steam商店页_字幕.srt` | 成片字幕（外挂版，时间轴与成片一致） |
| `成片/EP05_口播校对稿.txt` | 10 段录音的逐句校对稿 |

> 预览版 `视频/*.mp4` 走 Git LFS（克隆后需 `git lfs pull`）；成片是普通 Git 文件，网页上点文件再点 “Download” 即可直接下载。

## 正式成片（口播版）

`成片/EP05_Steam商店页_成片.mp4`：1920×1080 / 60fps，时长约 10 分 22 秒，画面来自 **真实案例版** 预览。

- **以录音为准**：10 段口播按编号顺序铺满全片，字幕逐句按录音内容重写，并对齐到实际说话时间；
  预览版里烧录的旧字幕已被同款字幕框覆盖替换。
- **画面跟着口播走**：每个画面段落对应口播里的那句话，按口播长度做了 0.6–1.3 倍变速，
  口播比画面长的地方在段尾定格。开场按录音顺序重排（先自我介绍，再三个参考题）；
  录音里没讲到的画面（“大厂可以慢慢铺”“我自己的排法”“多个视频怎么排”、
  “你的商店页卡在哪一步”“下期新手引导”）已剪掉，章节转场卡保留原速。
- **真实案例**：画面里的吸血鬼幸存者、小丑牌、蔚蓝、潜水员戴夫、渔帆暗涌、苦痛殿堂、土豆兄弟
  与口播一一对应；字幕里的游戏名按官方中文名写（如《渔帆暗涌》《苦痛殿堂》），
  语言选项沿用 Steam 界面的叫法“完全音频”。
- **声音**：口播做了降噪/压缩，响度约 -16 LUFS；《糖果物语》全程循环垫底，
  说话时自动压低约 4 dB、停顿和转场时回升，保证始终听得见；预览版自带音效保留并随画面变速。
